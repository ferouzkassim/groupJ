# StudentsRegistration
 a gui App for showing how to generate students and save them to a csv file 
 ### Classes / Objects.
 -RangesClass : gets ranges , from to , since i couldnt find an equivalence to it in java
 -Student : to create the student object
 -PasswordChecker : Checks passwords based ona regex

 ## run
 ```
java -jar StudentsRegitsration/target/StudentsRegitsration-1.0-SNAPSHOT.jar
```
or 
```
Double click it and run StudentsRegitsration/target/StudentsRegitsration-1.0-SNAPSHOT.jar
```
Saves data in the students.csv file
